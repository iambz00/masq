# 1차 프롬프트

아래 요구사항을 보고 파이선 코드를 짜 줘.
라이브러리 설치나 특별한 조치가 필요하다면 그 것도 모두 설명해줘야 해.

1. 목적
CCTV 영상 파일에 등장하는 인물에 대해, 사용자가 선택한 인물을 영상 끝까지 마스킹 처리 후 저장하는 것.
단, GPU를 사용할 환경이 안 되므로 딥러닝 방식은 피해야 함.
얼굴보다는 인물 전체를 마스킹하고 싶은데, 얼굴만 마스킹하는 것에 비해 비효율적이면 얼굴만 처리할 것.

2. UI 구성
영상 재생 창과, 사용자 행동에 대한 응답 로그를 보여주는 창 2개가 있어야 함.
첫 실행 시, 재생할 영상 파일을 선택해야 함
영상 재생 창에는 전후 탐색이 가능한 탐색 바 및 버튼을 배치하고, 프레임 단위 탐색도 가능해야 함.
영상 일시 정지 시 추적할 인물을 마우스 드래그로 선택할 수 있어야 하며, 인물별로 다른 색상의 사각 박스로 둘러싸서 마스킹해야 함
영상 재생 창은 크기를 조정할 수 있어야 하고 영상은 창 크기에 맞게 변해야 함.
0.25, 0.5, 1.0배로 조절할 수 있는 버튼 배치해야 함.
크기 조정 시 인물 선택이나 사각 박스 표시 위치가 어긋나지 않아야 함
응답 로그 창은 콘솔에 출력할 메시지를 같이 표시해야 하고, 영상 재생 창보다 위에 표시되어서 가려지지 않아야 함

3. 기능
재생 중 추적하던 인물을 놓치면 그 프레임에서 멈춰야 함.
opencv의 오탐으로 놓쳤을 수도 있고, 화면 밖으로 나가면서 추적이 풀려서 마스킹되지 않은 정보가 가장자리에 보일 수 있음
(이걸 해결할 좋은 방법이 있다면 적용 및 설명해 줘)
